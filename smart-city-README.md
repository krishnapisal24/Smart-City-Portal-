# Mumbai SmartCity Portal

A responsive React + Vite static website for a municipal Smart City Portal.

## Run in VS Code

1. Extract the ZIP.
2. Open the `smart-city-portal` folder in VS Code.
3. Open Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite (normally http://localhost:5173).

## Included

- Mumbai aerial hero image
- Sticky responsive navigation
- Live city ticker
- Live statistics
- Filterable service cards
- Infrastructure dashboard tabs
- Alerts
- City news
- Citizen complaint form
- Complaint tracker
- Quick poll
- Responsive mobile layout
- No backend required

The images use remote Unsplash URLs, so an internet connection is required for those images to load.
